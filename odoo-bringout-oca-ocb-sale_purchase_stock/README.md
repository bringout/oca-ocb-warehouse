# MTO Sale <-> Purchase


Add relation information between Sale Orders and Purchase Orders if Make to Order (MTO) is activated on one sold product.


## Installation

```bash
pip install odoo-bringout-oca-ocb-sale_purchase_stock
```

## Dependencies

- sale_stock
- purchase_stock
- sale_purchase
